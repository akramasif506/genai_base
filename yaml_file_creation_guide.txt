### image vs container.

	when the code package is build by docker it is image.
	when the same image is in running stage it is container.
	
	docker build  → creates the IMAGE
	docker push   → stores the IMAGE in Artifact Registry
	jobs deploy   → tells Cloud Run which IMAGE to use
	jobs execute  → Cloud Run starts a CONTAINER from that image, runs CMD, then the container exits
